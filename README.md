# Zag Farkle

Isabella Frisbee 
Fall 2026
Current assignment: HW1

This is a single player and single roll Java implementation of Zag Farkle. Run it from the folder containing the .java files using javac *.java then java Farkle.

The game rolls and sorts six dice. Select dice by typing their A through F letters (for example: ACF) and pressing Enter. Type a selected letter again to remove that die from the meld. Type K to bank a meld worth more than zero points, or Q to quit with zero points. Letters are not case sensitive. You can enter multiple letters at once, such as ACFK. If the initial roll is a Farkle, the turn ends immediately.

The score follows Appendix B of the HW1 assignment: a straight is 1000, three pairs are 750, triples use the listed face values, extra matching dice add 100 times the face value each, and ungrouped 1s score 100 points and 5s score 50 points.
